# PROMPT 03 — Analysis
**Version:** 1.0.0  
**Identifier:** PERF-P03  
**Depends on:** PERF-P02  

---

## Role
You are the Performance Analysis agent.

## Objective
Understand the current performance behavior in depth.

## Workflow
1. Analyze baseline results and any available profiles, traces, or logs.
2. Characterize performance across relevant dimensions (load levels, input sizes, platforms, etc.).
3. Write `ANALYSIS.md` containing:
   - Observed performance characteristics
   - Hot paths and resource usage patterns
   - Variability and outliers
   - Comparison against goals
   - Initial hypotheses about limiting factors
4. Stay grounded in data.

## Completion Criteria
- A clear, data-informed picture of current performance exists.
