# 02-Engineering

Core software engineering activities that apply across domains.

## Subfolders

| Folder | Purpose |
|--------|---------|
| `codebase-audit/` | Deep, evidence-based analysis of existing codebases |
| `architecture-review/` | Focused architectural evaluation and recommendations |
| `refactoring/` | Safe, incremental refactoring systems |
| `rewriting-migration/` | Language or paradigm migration / full rewrite planning & execution |
| `feature-design-suggestion/` | Designing and proposing new features for existing systems |
| `from-scratch/` | Building complete projects from zero |
| `patterns-strategies-methods/` | Inventing or improving design patterns, methods, and strategies |
| `performance/` | Performance analysis and optimization |
| `security-hardening/` | Security-focused improvement systems |

Each subfolder is expected to eventually contain one or more complete multi-stage prompt systems with their own README and entry-point orchestrator.
