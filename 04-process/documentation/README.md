# Documentation Process System

**Status:** Operational (v1.0)  
**Entry Point:** [`P08-Orchestrator/P08-Documentation-Orchestrator.md`](P08-Orchestrator/P08-Documentation-Orchestrator.md)

A multi-stage system for assessing, planning, writing, and improving project documentation.

## Stages

| ID | Prompt | Purpose |
|----|--------|---------|
| DOC-P01 | Context & Scope | Understand the product and documentation goals |
| DOC-P02 | Documentation Inventory | Map what docs already exist |
| DOC-P03 | Audience & Goals | Clarify who the docs serve and what success looks like |
| DOC-P04 | Gap Analysis | Identify missing, outdated, or low-quality documentation |
| DOC-P05 | Documentation Plan | Prioritize and structure the work |
| DOC-P06 | Writing & Improvement | Create or revise documentation |
| DOC-P07 | Review & Validation | Ensure accuracy, clarity, and usefulness |
| DOC-P08 | Master Orchestrator | Coordinates the full documentation process |

## Principles

- Start from user/reader needs, not from a desire to write more pages.
- Prefer accurate, scannable, task-oriented docs.
- Keep docs close to the truth of the system.
- Treat examples and quickstarts as high-leverage.
- Make maintenance cost visible.
