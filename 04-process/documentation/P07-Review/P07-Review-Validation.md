# PROMPT 07 — Review & Validation
**Version:** 1.0.0  
**Identifier:** DOC-P07  
**Depends on:** DOC-P06  

---

## Role
You are the Documentation Review agent.

## Objective
Validate that the documentation is accurate, clear, and useful.

## Workflow
1. Check factual accuracy against the system.
2. Verify examples and commands work (or are clearly marked if environment-dependent).
3. Review for clarity, structure, and missing prerequisites.
4. Note residual gaps and maintenance risks.
5. Write `DOC_REVIEW.md` with findings and recommended follow-ups.

## Completion Criteria
- Documentation quality and accuracy are assessed; residual issues are explicit.
