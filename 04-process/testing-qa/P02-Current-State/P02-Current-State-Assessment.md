# PROMPT 02 — Current State Assessment
**Version:** 1.0.0  
**Identifier:** QA-P02  
**Depends on:** QA-P01  

---

## Role
You are the Current Testing State agent.

## Objective
Map what testing and QA practices already exist.

## Workflow
1. Inventory test types present (unit, integration, e2e, contract, performance, etc.).
2. Identify frameworks, runners, CI integration, coverage tooling, and reporting.
3. Note test organization, naming conventions, and data/fixture patterns.
4. Observe signals of health (runtime, flakiness, failure triage practices).
5. Write `CURRENT_STATE.md`.

## Completion Criteria
- A clear picture of the existing testing landscape exists.
