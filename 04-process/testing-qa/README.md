# Testing & QA Process System

**Status:** Operational (v1.0)  
**Entry Point:** [`P07-Orchestrator/P07-Testing-QA-Orchestrator.md`](P07-Orchestrator/P07-Testing-QA-Orchestrator.md)

A multi-stage system for assessing, improving, and operationalizing testing and quality assurance practices in a software project.

## Stages

| ID | Prompt | Purpose |
|----|--------|---------|
| QA-P01 | Context & Goals | Understand product risk profile and quality goals |
| QA-P02 | Current State Assessment | Map existing tests, tools, and practices |
| QA-P03 | Gap Analysis | Identify coverage, quality, and process gaps |
| QA-P04 | Strategy & Prioritization | Design a practical improvement strategy |
| QA-P05 | Implementation | Add tests, tooling, or process improvements |
| QA-P06 | Validation & Measurement | Verify improvements and define ongoing signals |
| QA-P07 | Master Orchestrator | Coordinates the full Testing & QA process |

## Principles

- Align testing effort with real risk and user impact.
- Prefer meaningful tests over vanity coverage metrics.
- Make quality feedback fast and reliable.
- Improve incrementally; do not attempt a perfect system in one pass.
- Treat flaky tests as first-class problems.
