# Project Management Process System

**Status:** Operational (v1.0)  
**Entry Point:** [`P08-Orchestrator/P08-Project-Management-Orchestrator.md`](P08-Orchestrator/P08-Project-Management-Orchestrator.md)

A practical multi-stage system for planning, tracking, and steering software projects (or major workstreams) without heavyweight ceremony.

## Stages

| ID | Prompt | Purpose |
|----|--------|---------|
| PM-P01 | Context & Constraints | Understand the initiative, stakeholders, and constraints |
| PM-P02 | Goals & Success Criteria | Define outcomes and non-goals |
| PM-P03 | Work Breakdown | Decompose into actionable work packages |
| PM-P04 | Planning & Sequencing | Order work, identify dependencies, set checkpoints |
| PM-P05 | Execution Tracking | Maintain status, blockers, and next actions |
| PM-P06 | Risk & Adjustment | Handle risks, slips, and scope changes |
| PM-P07 | Review & Closeout | Evaluate outcomes and capture lessons |
| PM-P08 | Master Orchestrator | Coordinates the full project-management process |

## Principles

- Optimize for clarity and throughput, not bureaucracy.
- Prefer small visible increments and frequent checkpoints.
- Make risks, dependencies, and decisions explicit.
- Keep plans living documents.
- Distinguish committed scope from aspirational backlog.
