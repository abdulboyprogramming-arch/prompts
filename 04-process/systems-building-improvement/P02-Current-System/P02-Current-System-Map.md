## Objective
Document how the system actually works today, not how it is supposed to work.

## Workflow
1. Map primary flow(s) of work end-to-end.

3. Capture failure modes and workarounds people already use.
4. Write `CURRENT_SYSTEM_MAP.md` with flows, actors, tools, and pain observations.
