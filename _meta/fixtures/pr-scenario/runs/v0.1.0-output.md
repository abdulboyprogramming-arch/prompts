# feat(onboarding): promote ONBOARD-01 from skeleton to a tested takeover procedure

## What this changes

Promotes the codebase-onboarding prompt from a 55-line skeleton to a usable procedure. It was run as
written against a new takeover fixture, scored 0 of 9, was rewritten, and scored 9 of 9. The rewrite turns
the prompt from a description of a codebase into an evidence-based procedure ending in a takeover verdict
with conditions.

## Type

- [x] Promotion (skeleton/draft → operational)

## Summary

`ONBOARD-01` now executes the start procedure, reconciles models against the schema, checks the deployment
artifact, classifies secrets, maps personal data, reads the authorship, ranks the untested surface, makes
and reverts a change, and issues a verdict. The old version described and never ran anything.

## Motivation

The gallery line promised "join an unfamiliar codebase — where are the traps", and the prompt delivered a
brief that named no traps. This is the most common handover of 2026: a product built with an AI by someone
who cannot describe the code, handed to a developer who works by hand.
