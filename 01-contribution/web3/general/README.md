# General Web3 Contribution System

**Status:** Operational (v1.0)  
**Entry Point:** [`P08-Orchestrator/P08-Web3-Contribution-Orchestrator.md`](P08-Orchestrator/P08-Web3-Contribution-Orchestrator.md)

A practical multi-stage system for making high-quality contributions to Web3 projects. Covers smart contracts, dApps, frontends, indexing services, and related infrastructure while remaining adaptable across ecosystems (Ethereum, L2s, Solana, etc.).

## Stages

| ID | Prompt | Purpose |
|----|--------|---------|
| W3-P01 | Context & Project Understanding | Understand the protocol, stack, and contribution norms |
| W3-P02 | Discovery & Opportunity Identification | Find valuable contribution opportunities |
| W3-P03 | Opportunity Selection & Framing | Choose and clearly frame the work |
| W3-P04 | Planning & Design | Plan changes with Web3-specific considerations |
| W3-P05 | Implementation | Execute following project and ecosystem conventions |
| W3-P06 | Validation & Security Checks | Tests, static analysis, fork testing, basic security review |
| W3-P07 | PR & Communication | Prepare a professional pull request |
| W3-P08 | Master Orchestrator | Coordinates the full contribution flow |

## Web3-Specific Considerations

- Smart contract security and upgrade patterns
- Gas efficiency and economic design
- On-chain vs off-chain boundaries
- Wallet and transaction UX
- Indexing and data consistency
- Testnets, forking, and deterministic testing
- Auditability and formal verification signals
- Responsible handling of value-bearing code
