# Web Contribution Systems

Prompt systems specialized for contributing to web projects (frontend, backend, fullstack, and infra/devops aspects of web systems).

## Structure

| Path | Purpose |
|------|---------|
| `general/` | Core multi-stage web contribution system (stack-agnostic foundation) |
| `frontend/` | Frontend-specific extensions and deep prompts (React, Vue, Svelte, Solid) |
| `backend/` | Backend-specific extensions (APIs, services, databases) |
| `fullstack/` | Coordinated fullstack contribution patterns |
| `infra-devops/` | CI/CD, deployment, observability, and infrastructure contributions |

## Currently Available

- **general/** — Skeleton multi-stage Web contribution system: 8 stage outlines with sound sequencing but no evidence rules, verification, or failure handling yet. Useful for structuring a human-led session; not safe for unsupervised agent execution (entry point for most web contribution work)
