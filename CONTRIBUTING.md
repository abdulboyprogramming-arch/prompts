# Contributing to the Prompt Archive

Thank you for helping build the most complete professional prompt archive for software work.

## Adding a New Prompt System

1. Choose the correct location using `_meta/taxonomy.md`.
2. Create a dedicated subfolder for any multi-stage system.
3. Follow `_meta/prompt-template.md` for individual prompts.
4. Include a local `README.md` that explains:
   - Purpose of the system
   - Entry-point prompt
   - Required user context
   - Expected artifacts
5. Meet the bar in `_meta/quality-standards.md`.
6. Open a pull request with a clear description of what the new system enables.

## Improving Existing Systems

- Prefer additive improvements and version bumps.
- Keep backward-compatible entry points when possible.
- Document changes in the system’s own README or a CHANGELOG.

## Style

- Clear, direct technical language.
- Explicit over clever.
- Evidence and professional standards over hype.
